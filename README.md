# Simon

The classic Simon memory game in JavaScript. [Play it live](https://jeremypreed.com/games/simon/)

Press the small green button in the middle to start. Simon plays a pattern of colors; repeat it back. Each round adds one more step.

## How it's built

- Plain JavaScript, HTML and CSS. No frameworks or libraries.
- About 90 lines of JavaScript. Timers play the pattern back, and each click is checked against it.
- Each color has its own tone. A wrong press plays a buzzer and replays the pattern.
